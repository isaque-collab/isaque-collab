## Projetos em destaque

### Sistema de Gerenciamento de Biblioteca

Aplicação back-end desenvolvida em Java para gerenciar livros, usuários, empréstimos, devoluções, multas e relatórios.

**Principais implementações:**

* Operações CRUD com JDBC;
* Persistência de dados em MySQL;
* Controle transacional de empréstimos e devoluções;
* Validação de CPF, e-mail e ISBN;
* Controle de disponibilidade dos exemplares;
* Cálculo de multas com o padrão Strategy;
* Relatórios utilizando consultas SQL;
* Testes unitários e de integração;
* Interface de linha de comando.

**Tecnologias:** Java 21, Maven, JDBC, MySQL 8, Docker, JUnit 5, Log4j2 e Lombok.

[Ver projeto no GitHub](https://github.com/isaque-collab/Sistema-de-Biblioteca)

---

### Sistema Bancário

Aplicação Java criada para praticar Programação Orientada a Objetos, validações, exceções e persistência de dados.

**Principais implementações:**

* Cadastro de clientes e contas;
* Contas corrente e poupança;
* Depósitos, saques e transferências;
* Geração de extrato bancário;
* Validação de CPF, e-mail e telefone;
* Exceções personalizadas;
* Persistência local por serialização.

**Tecnologias:** Java, Maven, Collections, POO e JUnit 5.

[Ver projeto no GitHub](https://github.com/isaque-collab/Sistema-Bancario)
